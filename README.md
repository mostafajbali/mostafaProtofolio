# موقع مصطفى الجبالي — Photography & Video

موقع Portfolio عربي RTL بتصميم أسود سينمائي وذهبي، وخط Alexandria للعربية وManrope للنصوص اللاتينية، وتأثيرات حركة وظهور عند التمرير وقائمة هاتف.

## الملفات
- `index.html` محتوى الموقع.
- `style.css` التصميم والألوان والحركات والاستجابة للشاشات.
- `script.js` قائمة الهاتف وتأثيرات الظهور عند التمرير.
- `images/` مكان الصور الأصلية.

## مهم قبل النشر
**لا تتضمن هذه النسخة صورًا فوتوغرافية أصلية لأعمال مصطفى**؛ لأن ملفات الصور السابقة غير موجودة في الملفات المتاحة لي في هذه المحادثة. لم أستخدم صورًا تجريبية على أنها أعمالك. أضف صورتك الشخصية باسم `profile.jpg` داخل `images/`، وأضف صور مشاريعك بأسماء تختارها ثم عدّل بطاقات المعرض في `index.html` لتعرضها.

## الروابط
- البريد الإلكتروني والهاتف روابط فعلية للتواصل.
- أسماء بعض المؤسسات ترتبط بمواقعها الرسمية فقط، وليست روابط لأعمال محددة.
- لم أختلق روابط فيسبوك أو إنستغرام أو روابط مشاريع؛ أرسل الروابط الشخصية وروابط المنشورات الحقيقية حتى أضيفها.

## التشغيل والنشر
افتح `index.html` في المتصفح لمعاينة الموقع. ارفع جميع محتويات هذا المجلد إلى مستودع GitHub Pages، وليس ملف ZIP وحده. الخط من Google Fonts ويتطلب اتصالًا بالإنترنت، مع بقاء التصميم قابلًا للاستخدام بخط بديل إذا تعذر تحميله.
